# 电动汽车制动能量回收制动力分配计算方法（编程输入版）

> 本文档从设计方法原文抽取，仅保留计算链路所需的公式与判断逻辑，删除解释性文字。
> 符号约定：下标 `1`=前轴，`2`=后轴，`μ`=地面制动力，`z`=法向反力。

---

## 1. 输入参数

| 参数 | 符号 | 单位 | 说明 |
|---|---|---|---|
| 整车重力 | $G$ | N | $G=mg$ |
| 轴距 | $L$ | m | |
| 质心到前轴距离 | $a$ | m | |
| 质心到后轴距离 | $b$ | m | $a+b=L$ |
| 质心高度 | $h_g$ | m | |
| 轮胎滚动半径 | $R$ | m | |
| 主减速比 | $i_0$ | — | |
| 电驱外特性 | $T_{max}(n)$ | Nm | 馈电模式最大负扭矩，随转速 n 变化 |
| 电驱效率 | $\eta(n)$ | — | 馈电工况效率 |
| 电池最大充电功率 | $P_{max}(SOC, T)$ | kW | |
| 退出回收车速 | $V_{min}$ | km/h | 典型 5~10 |
| 关闭回收 SOC | $SOC_{max}$ | — | 典型 0.95~0.98 |
| 设计阈值 | $Z_{C1}, Z_{D1}$ | — | 前驱过渡段起止，典型 0.4 / 0.7 |
| 后驱阈值 | $Z_{B2}, Z_{C2}$ | — | 后驱过渡段起止，典型 0.1 / 0.15 |

**外部输入（每个控制周期）：** 制动强度需求 $Z$（$0\le Z\le 0.8$），车速 $V$（km/h），当前 SOC，电池温度。

---

## 2. 基础定义

- 总制动力需求：$F_\mu = G \cdot Z$
- 轮端转速：$n = \dfrac{V \cdot 1000}{60 \cdot 2\pi R} \cdot i_0 = \dfrac{V}{0.377\, R\, i_0}$（rpm）

---

## 3. I 曲线（理想制动力分配，前后轮同时抱死）

参数方程（参数为路面附着系数 $\varphi$，遍历 $\varphi \in [0, 1.0]$）：

$$
F_{\mu 1}(\varphi) = \varphi \frac{G}{L}(b + \varphi h_g)
$$

$$
F_{\mu 2}(\varphi) = \varphi G - F_{\mu 1}(\varphi)
$$

**关键性质：** 在 I 曲线上，$\varphi = Z$（制动强度 = 路面附着系数）。

**反查（给定 Z，取 I 曲线上的前轴制动力）：**

$$
F_{\mu 1}^{I}(Z) = Z \cdot \frac{G}{L}(b + Z \cdot h_g)
$$

---

## 4. M 曲线（ECE R13 法规下限边界）

ECE 法规要求：当 $\varphi \in [0.2, 0.8]$，

$$
Z \ge 0.1 + 0.85(\varphi - 0.2)
$$

**构造 M 曲线（参数方程，$\varphi \in [0.2, 0.8]$）：**

前轴最大可独立提供的制动力：

$$
F_{\mu 1}(\varphi) = \varphi \frac{G}{L}(b + \varphi h_g)
$$

判断条件：

$$
C(\varphi) = \frac{h_g}{L}\varphi^2 + \left(\frac{b}{L} - 0.85\right)\varphi + 0.07
$$

M 曲线纵标（后轴补足力）：

$$
F_{\mu 2}(\varphi) =
\begin{cases}
0, & 0.2 \le \varphi \le 0.8 \text{ 且 } C(\varphi) \ge 0 \\[4pt]
G[0.1 + 0.85(\varphi - 0.2)] - F_{\mu 1}(\varphi), & 0.2 \le \varphi \le 0.8 \text{ 且 } C(\varphi) < 0
\end{cases}
$$

**反查（给定 Z，取 M 曲线上的前轴制动力）：**

在 $C<0$ 区间，$Z = 0.1 + 0.85(\varphi - 0.2)$，反解：

$$
\varphi_M(Z) = \frac{Z - 0.1}{0.85} + 0.2
$$

$$
F_{\mu 1}^{M}(Z) = \varphi_M(Z) \cdot \frac{G}{L}\left(b + \varphi_M(Z) \cdot h_g\right)
$$

> 适用范围：仅当 $Z$ 落在 $C<0$ 对应的区间内。当 $C(\varphi)\ge0$ 时前轴可独立满足法规，$F_{\mu 2}=0$。

---

## 5. 前驱车型最优回收制动力线（前轴电驱）

目标：前轴承担尽可能多的制动力。

### 分段逻辑

**段 ①：纯前轴制动（$0 \le Z \le Z_{B1}$）**

$$
F_{\mu 1}^{req} = GZ, \quad F_{\mu 2}^{req} = 0
$$

其中 $Z_{B1}$ 是 $C(\varphi)=0$ 在 $\varphi \in [0.2, 0.8]$ 内的根对应制动强度：

$$
\frac{h_g}{L}\varphi^2 + \left(\frac{b}{L} - 0.85\right)\varphi + 0.07 = 0
$$

取有效根 $\varphi_{B1}$（落在 [0.2, 0.8] 内），则

$$
Z_{B1} = \varphi_{B1} \cdot \frac{b + \varphi_{B1} h_g}{L}
$$

**段 ②：沿 M 曲线（$Z_{B1} < Z \le Z_{C1}$，典型 $Z_{C1}=0.4$）**

$$
F_{\mu 1}^{req} = F_{\mu 1}^{M}(Z), \quad F_{\mu 2}^{req} = GZ - F_{\mu 1}^{req}
$$

**段 ③：M→I 线性过渡（$Z_{C1} < Z \le Z_{D1}$，典型 $Z_{D1}=0.7$）**

在 $Z=Z_{C1}$ 处取 M 曲线上的点，在 $Z=Z_{D1}$ 处取 I 曲线上的点，线性插值：

$$
F_{\mu 1}^{req}(Z) = F_{\mu 1}^{M}(Z_{C1}) + \frac{F_{\mu 1}^{I}(Z_{D1}) - F_{\mu 1}^{M}(Z_{C1})}{Z_{D1} - Z_{C1}} \cdot (Z - Z_{C1})
$$

$$
F_{\mu 2}^{req} = GZ - F_{\mu 1}^{req}
$$

**段 ④：沿 I 曲线（$Z > Z_{D1}$）**

$$
F_{\mu 1}^{req} = F_{\mu 1}^{I}(Z), \quad F_{\mu 2}^{req} = GZ - F_{\mu 1}^{req}
$$

> 注：段③的线性过渡为工程假设（原文仅描述"逐渐增加"），如实际标定有曲线，替换插值方式即可。

---

## 6. 后驱车型最优回收制动力线（后轴电驱）

法规约束：$Z \ge 0.15$ 时前轴利用附着系数须在后轴之上（即倾向前轮先抱死），故 $Z<0.15$ 区域可放开。

### 分段逻辑

**段 ①：纯后轴制动（$0 \le Z \le Z_{B2}$，典型 $Z_{B2}=0.1$）**

$$
F_{\mu 1}^{req} = 0, \quad F_{\mu 2}^{req} = GZ
$$

**段 ②：纯后轴→I曲线过渡（$Z_{B2} < Z \le Z_{C2}$，典型 $Z_{C2}=0.15$）**

线性插值，在 $Z=Z_{C2}$ 处取 I 曲线点：

$$
F_{\mu 1}^{req}(Z) = F_{\mu 1}^{I}(Z_{C2}) \cdot \frac{Z - Z_{B2}}{Z_{C2} - Z_{B2}}
$$

$$
F_{\mu 2}^{req} = GZ - F_{\mu 1}^{req}
$$

**段 ③：沿 I 曲线（$Z > Z_{C2}$）**

$$
F_{\mu 2}^{req} = GZ - F_{\mu 1}^{I}(Z)
$$

---

## 7. 电驱系统限值

$$
F_{Mot}^{edrv} =
\begin{cases}
0, & V \le V_{min} \\[4pt]
\dfrac{T_{max}(n)}{R}, & V > V_{min}
\end{cases}
$$

其中 $n$ 为轮端转速（按第 2 节公式由 $V$ 换算）。

---

## 8. 电池系统限值

$$
F_{Mot}^{bat} =
\begin{cases}
0, & SOC \ge SOC_{max} \\[4pt]
\dfrac{9554 \cdot P_{max}(SOC, T)}{\eta(n) \cdot n \cdot R}, & V > V_{min} \text{ 且 } SOC < SOC_{max}
\end{cases}
$$

> 9554 来源：$P(\text{kW}) = T(\text{Nm}) \cdot n(\text{rpm}) / 9554$，反解 $T = 9554 P / n$，再除以 $R$ 得轮端力。

---

## 9. 最终回收制动力（融合）

电驱轴可提供的最大回收制动力：

$$
F_{Mot}^{max} = \min\left(F_{Mot}^{edrv},\; F_{Mot}^{bat}\right)
$$

实际下发的回收制动力：

$$
F_{Mot}^{cmd} = \min\left(F_{Mot}^{max},\; F_{drive\text{-}axle}^{req}\right)
$$

其中 $F_{drive\text{-}axle}^{req}$ 为第 5 节（前驱取 $F_{\mu 1}^{req}$）或第 6 节（后驱取 $F_{\mu 2}^{req}$）算出的电驱轴需求制动力。

剩余机械制动由非电驱轴补足：

$$
F_{non\text{-}drive}^{mech} = GZ - F_{Mot}^{cmd} - F_{other\text{-}axle}^{mech}
$$

（工程上由液压制动系统按策略分配，本文档不展开。）

## 10. 计算流程伪代码

```python
def calc_regenerative_braking(Z, V, SOC, T_bat, params, drive_type="FWD"):
    # --- 第2节 基础量 ---
    G, L, a, b, hg, R, i0 = params.G, params.L, params.a, params.b, params.hg, params.R, params.i0
    n = V / (0.377 * R * i0)   # rpm
    F_mu_total = G * Z

    # --- 第5/6节 策略需求 ---
    if drive_type == "FWD":
        F_drive_req = FWD_strategy(Z, G, L, b, hg, Z_C1=0.4, Z_D1=0.7)
    else:
        F_drive_req = RWD_strategy(Z, G, L, b, hg, Z_B2=0.1, Z_C2=0.15)

    # --- 第7节 电驱限值 ---
    F_edrv_max = 0.0 if V <= params.V_min else T_max(n) / R

    # --- 第8节 电池限值 ---
    if SOC >= params.SOC_max or V <= params.V_min:
        F_bat_max = 0.0
    else:
        P_max = battery_max_charge_power(SOC, T_bat)
        eta = motor_efficiency(n)
        F_bat_max = 9554.0 * P_max / (eta * n * R)

    # --- 第9节 融合 ---
    F_mot_max = min(F_edrv_max, F_bat_max)
    F_mot_cmd = min(F_mot_max, F_drive_req)

    return F_mot_cmd, F_mu_total - F_mot_cmd   # 回收力, 机械补生力
```

辅助函数：

```python
def F_M1_I(Z, G, L, b, hg):
    # I曲线反查：前轴制动力
    return Z * G / L * (b + Z * hg)

def F_M1_M(Z, G, L, b, hg):
    # M曲线反查：前轴制动力（C<0区间）
    phi = (Z - 0.1) / 0.85 + 0.2
    return phi * G / L * (b + phi * hg)

def solve_Z_B1(G, L, b, hg):
    # 解 C(phi)=0 的二次方程，取 [0.2,0.8] 内的根
    A = hg / L
    B = b / L - 0.85
    C = 0.07
    disc = B**2 - 4*A*C
    roots = [(-B + disc**0.5)/(2*A), (-B - disc**0.5)/(2*A)]
    for phi in roots:
        if 0.2 <= phi <= 0.8:
            Z_B1 = phi * (b + phi*hg) / L
            return Z_B1
    return 0.0  # fallback
```
