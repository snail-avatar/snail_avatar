# Core 目录

此目录包含所有核心功能模块，是系统的公共中台层。

## 目录结构

```
core/
├── __init__.py              # 包初始化文件
├── calc_nodes_base.py       # 计算节点基类
├── memory_database.py       # 内存数据库管理
└── config.py                # 配置管理
```

## 主要模块

1. **CalculationNode**：计算节点基类，提供计算节点的通用功能
   - 三层次变量系统（SSTS、INTER、VTS）
   - 状态机管理计算节点生命周期
   - 模板方法模式实现计算逻辑

2. **MemoryDatabase**：内存数据库管理
   - 数据的存储和检索
   - 从 Excel 文件加载数据
   - 导出数据到 Excel 文件

3. **ConfigManager**：配置管理
   - 读取和解析配置文件
   - 提供配置值的获取方法

## 功能说明

- **计算节点框架**：提供统一的计算节点接口，支持各种计算任务
- **内存数据库**：管理系统中的所有数据，包括输入参数、中间变量和输出结果
- **配置管理**：处理系统配置，提供灵活的配置选项
